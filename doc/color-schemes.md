# Color schemes

The active palette is `public/data/color.json`. To switch themes, replace that file with one of the complete objects below. A deployed site can update `dist/data/color.json` directly without rebuilding.

## Deep Ocean (default)

```json
{
  "name": "Deep Ocean",
  "background": "#061018",
  "surface": "#0a1821",
  "surfaceElevated": "#10242f",
  "brand": "#0d9488",
  "brandLight": "#5eead4",
  "accent": "#38bdf8"
}
```
